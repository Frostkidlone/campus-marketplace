
# FUPRE Market — Online Marketplace for Campus Students

Production-ready final year project implementing the exact requirements from Chapter 1-3:

**Three-Tier Architecture:** Presentation (React + Tailwind Premium UI) | Application (Node.js + Express) | Database (SQLite / MySQL)

### ✅ Coverage of Functional Requirements (FR1-FR14)
- FR1 Registration, FR2 Login, FR3 Logout, FR4 Profile, FR5 Create, FR6 Edit, FR7 Delete, FR8 Status, FR9 Search, FR10 Filter, FR11 Details, FR12 Contact, FR13 Messaging, FR14 Categories

### Quick Start
```bash
cd backend
npm install
npm run init-db
npm run dev

# new terminal
cd frontend
npm install
npm run dev
```
